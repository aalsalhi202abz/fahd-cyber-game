# مغامرة فهد في الأمن السيبراني

لعبة تعليمية لطلاب المرحلة الابتدائية – **مبادرة الأمن السيبراني**
إعداد ومشاركة الطالب: فهد عبدالعزيز الصالحي – الصف الثالث الابتدائي
مدرسة أم المؤمنين أم سلمة للطفولة المبكرة بغالب – 1448هـ
إشراف المعلمة: ميار الصالحي · مديرة المدرسة: شيخه الصحبي

> ألعب وأتعلم.. وأحمي نفسي في العالم الرقمي

## ملفات المشروع

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية وكل الشاشات |
| `style.css` | التصميم (RTL، متجاوب مع الجوال) |
| `data.js` | بنك الأسئلة (24 سؤالًا) والمواقف (16، يظهر 5 منها كل جولة) |
| `icons.js` | شخصية فهد والأيقونات (SVG محلي) |
| `game.js` | منطق اللعبتين، الوسام، رمز QR، الصوت |
| `qrcode.js` | مكتبة توليد رمز QR (رخصة MIT) |
| `cairo-*.woff2` | خط Cairo محلي (يعمل بدون إنترنت) |
| `moe-logo.png` | شعار وزارة التعليم |
| `fahd.png` | اختياري: ارفع صورة فهد الكرتونية بهذا الاسم لتحل محل الشخصية الافتراضية |

## التشغيل على الكمبيوتر

**الأسهل:** افتح ملف `index.html` بالضغط المزدوج (Chrome أو Edge).

**الأفضل (لظهور الصور الاختيارية وتحميل الوسام):** شغّل خادمًا محليًا داخل المجلد:

```bash
python -m http.server 8000
```

ثم افتح: `http://localhost:8000`

## النشر المجاني على GitHub Pages (خطوة بخطوة)

1. أنشئ حسابًا مجانيًا على **github.com** (إن لم يكن لديك).
2. اضغط **+** أعلى اليمين ← **New repository**.
3. اسم المستودع: `fahd-cyber-game` ← اختر **Public** ← **Create repository**.
4. في صفحة المستودع اضغط **uploading an existing file**.
5. افتح مجلد اللعبة على جهازك، حدّد **كل محتوياته** (index.html وبقية الملفات) واسحبها إلى الصفحة.
   ⚠️ اسحب المحتويات نفسها، وليس المجلد الأب، حتى يكون `index.html` في جذر المستودع.
6. اضغط **Commit changes**.
7. اذهب إلى **Settings** ← **Pages** (من القائمة الجانبية).
8. في **Source** اختر **Deploy from a branch**، ثم **Branch: main** و**/(root)** ← **Save**.
9. انتظر دقيقة إلى دقيقتين، ثم حدّث الصفحة. سيظهر الرابط بهذا الشكل:

```
https://اسم-المستخدم.github.io/fahd-cyber-game/
```

الرابط يعمل بـ **HTTPS** تلقائيًا. افتحه من الجوال للتأكد.

> ملاحظة: ملف `.nojekyll` مخفي في بعض الأجهزة؛ وجوده مفيد لكنه ليس ضروريًا لعمل اللعبة.

## خيار بديل: Netlify (أسرع طريقة)

1. ادخل **app.netlify.com/drop**
2. اسحب مجلد اللعبة كاملًا إلى الصفحة.
3. يظهر رابط فورًا مثل `https://اسم-عشوائي.netlify.app` – يمكن تغيير الاسم من **Site settings ← Change site name**.

## المشاركة ورمز QR

1. افتح اللعبة من رابطها المنشور.
2. في أسفل الصفحة الرئيسية اضغط **«مشاركة اللعبة ورمز QR»**.
3. سيظهر الرابط تلقائيًا (أو الصقه)، ثم اضغط **إنشاء رمز QR**.
4. اضغط **تحميل الرمز (PNG)** لطباعته في المدرسة أو إرساله في مجموعات أولياء الأمور.

**نص جاهز للواتساب:**

```
🛡️ مبادرة الأمن السيبراني – مغامرة فهد
لعبة تعليمية لأطفالنا: ألعب وأتعلم.. وأحمي نفسي في العالم الرقمي
افتح الرابط والعب:
https://اسم-المستخدم.github.io/fahd-cyber-game/
```

## الخصوصية

- لا تسجيل دخول، ولا قاعدة بيانات، ولا خادم.
- الاسم الأول (اختياري) يُرسم على الوسام داخل الجهاز فقط ولا يُرسل لأي جهة.
- الحفظ الوحيد في المتصفح هو تفضيل تشغيل/إيقاف الصوت.
